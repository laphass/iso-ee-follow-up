# ISO EE FOLLOW UP

Dashboard สำหรับแผนตรวจเช็คเครื่องจักรและระบบไฟฟ้า 46 รายการ

## การใช้งาน

เปิด `index.html` ผ่าน GitHub Pages หรือ static web server หน้าเว็บอ่าน `data/records.json` จาก repository นี้ สามารถค้นหาและกรองตามรอบงานได้

ฐานข้อมูลนี้เริ่มต้นใหม่โดยไม่มีบันทึกประวัติจากระบบเดิม การบันทึกผ่านแบบฟอร์ม Dashboard ยังไม่เปิดใช้งาน ผู้มีสิทธิ์ repository สามารถแก้ไข JSON ผ่าน GitHub และกดโหลดข้อมูลล่าสุดใน Dashboard

## โครงสร้างข้อมูล

`data/records.json` มี `schemaVersion: 1` และ `records` ซึ่งแต่ละบันทึกประกอบด้วย `id`, `cycle`, `status`, `progress`, `owner` (ผู้ตรวจเช็ค), `checker` (ผู้ตรวจสอบ), `doc`, `reason`, `reasonNote`, `note`, `at` และ `by`

รหัสรายการใช้รอบงานและลำดับจากแผน เช่น `M-0` และรอบ `2026-10`; ไตรมาสใช้ `2026-Q4`, ครึ่งปีใช้ `2026-H2`, รายปีใช้ `2026` สถานะงานคือ `todo`, `doing`, `done` ความคืบหน้าอยู่ในช่วง 0–100

Repository เป็น Public ข้อมูลที่บันทึกจะอ่านได้โดยบุคคลทั่วไป สิทธิ์แก้ไขควบคุมด้วย GitHub ไม่มี access token หรือรหัสผ่านของระบบเดิมในไฟล์เผยแพร่

## ฟอนต์

หน้าเว็บเรียก PK Maehongson จากฟอนต์ที่ติดตั้งในเครื่องเท่านั้น และมี Segoe UI/Tahoma สำรอง ไม่มีการแจกไฟล์ฟอนต์ การใช้งานองค์กรต้องเป็นไปตามสิทธิ์จาก Pocket Fonts
